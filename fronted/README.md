# Easy Community 前端

React + TypeScript + Vite，使用原生 CSS 与 React Router。目录名称沿用仓库中的 `fronted`。

## 启动与构建

建议使用 Node.js 24 LTS 和 npm。本次验证环境为 Node.js 24.18.0、npm 11.16.0；依赖版本以 `package-lock.json` 为准。

```powershell
cd fronted
npm ci
npm run dev
```

浏览器访问 `http://127.0.0.1:5173`。开发服务器与构建预览显式监听 IPv4，避免 localhost 解析到 IPv6 时连接失败。Vite 将相对 `/api` 请求转发到 `http://127.0.0.1:8080`，保留 Host、路径前缀和 Cookie。开发时统一使用 127.0.0.1，避免与 localhost 混用导致 Cookie 隔离。

```powershell
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

浏览器测试在 5175 端口自动启动生产构建预览，不占用 5173。测试接口仅在 Playwright 浏览器内拦截，不依赖后端；失败保留截图和 trace，布局截图位于 `test-results/`。页面没有生产环境的假数据或模拟登录开关。

构建结果位于 `dist/`。部署时由静态服务器承载，前端路由回退 `index.html`，并在同一 Origin 下转发 `/api/` 到后端，可参考仓库 `backend/examples/nginx.conf.template`。`vite preview` 只用于本地验收。

## 已实现边界

- `/`：主页三栏、顶部与侧栏吸顶、静态横幅、推荐流连续加载。最小宽度 1440px，窄屏横向滚动，背景固定覆盖视口。
- `/login`：账号密码登录、必填反馈、密码显隐、CSRF、提交锁、限流倒计时与登录后返回首页。小于 1024px 时优先显示表单，短窗口允许纵向滚动。
- `/manage/articles`：本人公开文章、内部滚动、游标续页、保留旧内容的刷新、删除确认与结果核对。首页“管理作品”进入，游客登录成功后回跳；新历史项读取首批，浏览器后退恢复同一历史项的文档内列表和位置。
- `/users/:userId`：游客可读的个人主页，真实资料和作者公开文章；整页统一滚动，同一张资料卡固定在顶栏下方并从376px连续收至88px，头像96px渐缩至48px。上下间距保持43px／17px，发布栏与右侧信息卡在同一上缘吸顶，列表上缘用独立圆角表面遮挡经过的内容。文章返回恢复文档内列表及锚点。最小宽度1440px，窄屏横滚。
- 真实接口：`GET /api/articles/feed`、`GET /api/auth/session`、`GET /api/users/{userId}`、`GET /api/auth/csrf`、`POST /api/auth/login`、`POST /api/auth/logout`、`GET /api/users/me/articles`、`DELETE /api/articles/{id}`及结果核对使用的`GET /api/articles/{id}/edit`。数据类型直接对应后端 DTO，ID 始终使用字符串。
- 编辑接口：`GET /api/articles/{id}/edit`、`POST /api/articles`、`GET /api/tags?q=…&limit=20`、`POST /api/media/uploads`；所有写操作携带当前会话 CSRF，不自动重发文章或文件上传。
- `/articles/new`、`/articles/:id/edit`：完整 Tiptap 正文、封面与正文图片上传、标签搜索、发布保存弹窗、离开确认，身份失效直接进入登录且不恢复旧内容。保存成功留在编辑页，新建转为同 ID 编辑。
- 共用 Banner：登录后头像悬停或点击展开菜单，支持方向键和 Esc。个人主页、内容管理与设置均在新标签页打开。登出成功按当前页面分流，公开页原址刷新，受保护页进入显式登录，游客显示浅蓝底黑字的登录按钮。编辑器未保存时先确认放弃，取消不发送登出；失败保留原文。
- 首页与阅读页作者头像和名字当前标签页进入作者主页；搜索、热门、关注、视频、合集和评论保留未开放提示，不增加注册、找回密码或记住登录。
- 作者头像使用真实地址，缺失或加载失败回退默认头像，评论数显示“—”；浏览、点赞数量及本人点赞状态使用真实接口数据。

推荐流每次固定读取20项，以 `nextCursor=null` 判断结束；空页不等于结束。连续三页没有新文章时暂停自动请求，允许手动继续。失败保留内容，限流遵守 `Retry-After`；过期或无效游标需点击重新加载，重新从首屏开始。列表暂不虚拟化，持续浏览会增加 DOM 数量。

登录态仅来自 `GET /api/auth/session`，全局只保存 `userId、role` 和会话运行状态。首次401表示游客，网络或503保留未知态；后台复核失败保留已确认身份并暂停新操作。导航和设置页各自读取公开资料，失败统一提示“加载失败，请稍后重试”，不提供资料重试按钮或缓存。Session ID仅通过HttpOnly Cookie传递，CSRF只留内存。

会话失效、退出成功或复核发现换号时，首页、个人主页和文章浏览页保留当前URL整页刷新；管理、新建、编辑和资料设置页整页进入 `/login?returnTo=...&reauth=1`，登录完成整页返回合法地址。初次游客直接访问受保护页也进入该入口。显式登录标记防止另一有效账号自动跳过登录表单；返回地址只接受站内白名单，其余回首页。窗口聚焦仍复核会话，不做跨标签页广播；浏览器从往返缓存恢复旧文档时重新加载，避免复活旧账号画面。

身份边界取消在途读取、作废旧回调并卸载旧页面；公开读取不再遇401后静默重读。登录成功隔离登录前请求，再刷新CSRF，不等待资料加载或重复认证。不保存或恢复会话失效前的编辑内容，并清除旧版sessionStorage暂存。普通编辑离页确认保留；身份边界不被旧编辑页阻断。列表快照仍限当前文档，普通导航沿用，用户手动刷新获取新列表，不新增缓存隔离体系。用户名仅去首尾空白，密码原样发送。

管理列表每次20条，距离底部200px续页，以`nextCursor=null`结束；空页仍可续读，连续三页无新增则暂停自动读取，同游标重复则重开查询。首次显示五条骨架，追加失败只显示原稿一行“加载失败，点击重试”；刷新期间保留旧条目，成功替换并只让列表回顶，失败保留内部数据和位置、展示同一加载失败态并停用旧游标。游标无效、过期和429保留必要的重试及冷却逻辑，不另设技术状态说明。列表无观察器时支持手动加载，不定时轮询，也不虚拟化。

管理页不展示精确总数；阅读及点赞为真实值，评论和收藏显示“—”。删除先取得CSRF，204后才移除；前置凭证失败不发送DELETE。写入结果未知时不自动重发，用户主动通过作者接口核对；隐藏409或不存在404时移除，200保留并允许重新确认。已确认移除的ID在本页内排除，防止短暂旧卡片和迟到响应重新展示。该排除状态离开页面即清理。
