## 功能与边界

- 入口：公共导航搜索框；可直接访问 `/search` 或 `/search?q=社区设计&sort=relevance`。
- 只搜索后端现有的文章标题；每页 20 条，使用后端游标，不展示总结果数。
- 输入与已提交条件分离。回车或按钮提交，组词回车不提交；新词恢复相关度；排序只作用于当前已提交关键词。
- 清空按钮只改输入。空词提交提示并保留结果；最多 100 个 Unicode 码点，超限不请求。
- 草稿不保存到历史；历史返回同步已提交关键词，并恢复文档内的文章快照、续页游标和阅读位置。
- 登录返回保留已提交关键词和排序，整页重新查询，不恢复跨身份快照，不自动重放点赞。关注和评论仍提供未开放反馈。
- 连续三页无新增内容暂停自动续页；重复、无效、过期游标要求手动重载。续页出错保留已读内容，429 重试遵守倒计时。
- 快照沿用现有最多 20 项的内存缓存；整页刷新、缓存淘汰后重新读取首屏。

## 用户手动验收清单

以下项目留给用户操作确认，自动检查不代表已完成视觉或交互验收。

- [ ] 从首页及其他公共导航输入关键词，回车和按钮均能进入搜索页；进入后只显示一处独立搜索框。
- [ ] 中文输入法回车选词不提交；清空后结果保留；提交空词提示；100 个表情可提交，101 个字符提示超限。
- [ ] 当前选择最新后提交新词，恢复相关度；重复提交相同词不请求；修改草稿后点击排序，仍查询原已提交关键词。
- [ ] 直接访问 `/search` 显示待搜索状态；超长 URL 关键词显示参数提示，排序不可用；刷新有效搜索地址可正常加载。
- [ ] 1440×1024 对照设计，检查导航、搜索框、排序栏、右侧发布卡片和蓝色聚焦／悬停样式。
- [ ] 检查有封面、无封面、封面加载失败、长标题、长作者名；封面保持 224×126px，标题摘要最多两行。
- [ ] 在文章、导航、发布卡片及空白处滚动均推动同一页面；文章不能穿透搜索框、间隔和排序栏背景。
- [ ] 在 1280×768、390×844 和宽屏下检查统一横向滚动、窗口缩放及右侧发布入口，文档本身不额外滚动。
- [ ] 结果较短时自动补页；触底只续页一次；到达结束后不再请求；连续无新增内容可手动继续。
- [ ] 网络失败、503、429、游标失效时检查文案及按钮；续页失败保留文章，重新加载回顶且保留横向位置。
- [ ] 从深层结果进入详情或作者主页后退，恢复同一文章及相对位置；图片加载不改变阅读锚点，手动滚动后不争抢位置。
- [ ] 关键词和排序切换后前进／后退，各历史项恢复自己的结果和输入；主动重载后离开不会恢复旧失效游标。
- [ ] 游客通过导航或点赞进入登录，成功后返回原关键词和排序，从首屏查询；不会自动点赞。取消登录后退可恢复原列表。
- [ ] 登录用户点赞和取消点赞可用；身份未知时禁用写入；关注、评论仍显示未开放反馈。

## 当前设计约束

本期保留桌面固定画布与横向浏览方式。窄屏尚无独立移动端排版；后续若增加移动端，应统一规划主页和搜索页的布局及吸顶高度，而不是单独缩放搜索卡片。
