## 接口与状态约定

复用现有文章保存、作者读取、标签搜索和媒体授权；无后端 Java 代码或数据库变更。正文适配 `schemaVersion=1`，图片提交 `fileId`，不信任客户端 src；保留标题层级、两种列表、起始序号、引用、代码语言、六种文字样式及 HTTP(S) 链接。真实后端负责规范化 HTML、摘要和引用。

文章创建由不存在转公开；修改保持公开并更新修改时间，已删除不可编辑。上传任务留在本地界面，不写入正文协议。提交弹窗为处理中→成功/失败，处理中不允许重复提交；新建成功后的后续写入携带原 ID。失败保留输入，但失败反馈不证明数据库一定未提交，人工重发新建可能重复。

开发 Vite 仅把固定桶 MinIO POST 的 200、ETag、请求 ID 转换为统一成功 JSON；错误、连接中断或缺少成功证据均失败。无固定等待、状态查询、发布接口或自动上传重试；原有 MinIO Webhook、生产 COS Callback、READY 校验保持现状。未来头像开发延迟不在本轮实施。
