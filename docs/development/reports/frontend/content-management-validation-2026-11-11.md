## 设计对照修正

再次对照状态稿`242:7808`及交互说明后，发现原实现把内部状态直接变成了设计稿之外的展示。按页面可见状态收敛如下，原有身份校验、请求隔离及删除安全逻辑保留：

| 内部情况 | 页面展示 |
|---|---|
| 首次身份/文章读取、身份失败后的主动重试 | 原稿五条骨架 |
| 普通后台身份复核 | 静默复核，布局和位置不变 |
| 身份读取失败、首次文章失败、刷新失败 | 原稿“内容加载失败／请检查网络连接后重试／重新加载” |
| 追加失败、无效或过期游标 | 尾部一行“加载失败，点击重试”，内部决定原游标重试或重开查询 |
| 空列表 | 原稿“暂无已发布内容”、说明和单一去发布按钮 |
| 无封面、图片加载失败 | 同一无封面占位 |
| 删除结果未知 | 原确认弹窗内说明及核对入口，标题保持“删除这篇内容？” |

移除身份确认/暂停操作提示条、工具栏刷新错误横幅、追加失败的重复说明、列表尾部的刷新提示及空状态重复刷新入口。错误遮盖层保留不可交互的原列表节点与滚动位置，身份重试成功恢复原位置，刷新成功后回顶。

状态图标改用`242:7867`原始64px SVG；标题18px、按钮104×36和蓝色背景均按原稿。浏览器断言验证771px基准视口内图标、标题、按钮分别位于230/316/402px；身份失败和首次失败采用同一组件。

本轮单元测试52项通过；管理页浏览器用例14项覆盖静默复核、统一失败态、隐藏旧列表的不可交互性、原位置恢复、原稿几何及既有分页/删除行为。此前全量26项浏览器验收记录保留为上一轮结果。
