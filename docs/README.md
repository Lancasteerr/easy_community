# 文档中心

文档先按最终用途分类，再按文体和功能组织。

- [公开文档](public/README.md)：面向仓库使用者，随当前实现维护，采用“文体 → 功能 → 语言”。已有中文和英文版本分别保留，不要求每篇补齐翻译。
- [开发过程资料](development/README.md)：供开发协作和历史追溯，采用“文体 → 功能”，统一使用中文，不设置语言目录、不维护英文版本。

公开文档包含架构（architecture）、有效设计（designs）、接入指南（guides）和运维手册（operations）。过程资料包含行动计划（plans）、原始交接（handoffs）、审阅（reviews）、历史设计（designs）和报告及原始数据（reports）。各文体下按需建立 backend、article、search、like、media 功能目录，不创建空目录。

混合文档按主用途归类，本轮不拆正文。保留文件名、版本号、日期和历史结论；历史实施步骤或验收结果不代表当前版本的待办或重新验收结果。公开文档应能独立使用，不依赖开发过程资料。

本次仅在仓库内分类，不删除资料、不迁出仓库。开发过程资料后续可整体移出，迁出位置、时机及删除均由维护者亲自确认和操作；原路径、现位置与历史关系见开发过程资料清单。
